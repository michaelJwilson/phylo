How much alignment the search needs to recover the tree that generated it. Each marker is one independent alignment drawn from the 4-state Jukes-Cantor fixture (seed 20260905, 8 replicates per size), inferred by NNI hill climbing and scored against the generating topology by normalized Robinson-Foulds distance -- 0 for the same tree, 1 for no internal split in common. The dotted line is the accuracy requirement this project set itself, 0.05. It is met from 125 sites upward: 8 of 8 replicates recover the topology exactly at 2000 sites, against 5 of 8 at 60. The distance is normalized by internal splits, so the bound means the same thing at any taxon count.
