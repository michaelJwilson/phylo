Two implementations and two methods, so agreement is evidence rather than self-consistency. (b) The same disagreement swept over h, x axis reversed so h decreases rightwards. The curve is U-shaped: truncation error falls as h shrinks while floating-point cancellation grows, best here at h = 1e-06 (6.14e-07). A finite-difference check is only meaningful near that minimum, which is why the step is stated. Disagreement is reported relative to the gradient magnitude: the regression tests pin an absolute 1e-06 at 30 sites, but the gradient scales with the site count, so the same agreement reads as 1.03e-06 absolute here and an absolute bound fixed at one size does not transfer.
