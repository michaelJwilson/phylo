A `drafted` label completes the ticket lifecycle, `(unlabelled) -> planned -> approved -> drafted`. It marks a ticket whose work is open as a pull request, which a maintainer must otherwise distinguish from an unstarted one by reading the thread; the merge closes the ticket rather than labelling it again. `drafted`, `inprogress`, `blocked` and `module:cross-cutting` were already applied in the repository but absent from `.github/labels.yml`, which claims to be the only way labels change; all four are now recorded there, in the colours they already wear.
